# Head Shop — Fabric 1.21.11

Player heads are PvP currency. Killing a player awards one Head up to a maximum of 15. Right-click a currency Head to open the shop.

## Upgrades
- Combat: Strength I–III, Haste I–III
- Defense: Hearts up to 20 total, Resistance I–III, Regeneration, Fire Resistance
- Mobility / Utility: Speed I–III, Jump Boost I–III, Night Vision, Water Breathing

Upgrade costs are sequential: I = 1 Head, II = 2 Heads, III = 3 Heads. `/headreset` requires operator permission level 2.

Target: Minecraft 1.21.11, Fabric, Java 21.
